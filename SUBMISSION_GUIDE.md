# CodeAlpha C Programming – Submission Guide

This package contains four separate C projects corresponding to the four tasks in the CodeAlpha C Programming task sheet.

## Folder structure
- `CodeAlpha_Calculator/` – Basic calculator using switch-case.
- `CodeAlpha_Matrix_Operations/` – Matrix addition, multiplication and transpose using functions and 2D arrays.
- `CodeAlpha_Student_Management_System/` – Student CRUD operations using structures and file handling.
- `CodeAlpha_Banking_System/` – Account creation, deposit, withdrawal and balance enquiry using structures and file handling.

Each project folder contains its source code and its own README with build instructions and test cases.

## Build environment
The projects are written in standard C and can be compiled with GCC. In Windows PowerShell, open the relevant project folder and run the command in that folder's README.

## Before submitting
1. Compile each `.c` file on your own Windows PC using GCC.
2. Run the test cases in each README.
3. Capture screenshots of successful execution from your computer.
4. Record a short explanation video for each project.
5. Create a GitHub repository named `CodeAlpha_C_Programming` and upload the four project folders.
6. Upload the complete project folder to the submission location specified by CodeAlpha.
7. Submit using the official form shared with your internship group.

## Suggested GitHub repository description
Four C programming projects developed for the CodeAlpha C Programming internship: calculator, matrix operations, student management system and banking management system.

## Suggested video outline
- Introduce yourself and the project.
- Explain the problem and project features.
- Briefly explain the main C concepts and functions used.
- Demonstrate the program with sample inputs.
- Show the GitHub repository.

## Academic honesty and verification
Review and understand the source code before submitting it. Run all programs locally and use your own screenshots and video demonstration. These are educational projects and are not production-grade financial or student-record systems.

## Internship timing
The task sheet states that interns should complete at least two or three tasks and submit through the form shared in their respective group. Since the internship period has passed, confirm with CodeAlpha that late submissions are still accepted before relying on them for certificate eligibility.
